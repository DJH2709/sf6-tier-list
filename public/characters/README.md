# Character portraits

Drop one image per character here, named by the character's id from `src/lib/sf6.ts`,
for example `ryu.png`, `chun-li.png`, `e-honda.webp`, `a-k-i.png`. Square images, at
least 128x128, look best. Characters without an image show their initials instead.

The list of available portraits is rebuilt automatically on `npm run dev` and `npm run build`.

Who owns the art is your call. Official Capcom renders are Capcom's copyright, and
Capcom's fan content guidelines do not cover using their images as-is. Art you drew or
commissioned is yours.
